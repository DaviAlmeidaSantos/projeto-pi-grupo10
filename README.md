# Projeto Integrador — Grupo 10

Repositório do Grupo 10 para a disciplina de Pesquisa e inovação (PI), SPTECH.

## Estrutura do repositório

- **`Colaborativo/`** — Projeto principal do grupo: estimação periódica do volume da
  cana-de-açúcar por meio de múltiplos sensores ultrassônicos, com banco de dados,
  documentação, sites e prototipação.

- **`Individuais/`** — entregáveis individuais de cada membro, organizados por
  nome e sprint (ex: `Individuais/<nome>/sprint_01/`).

- **`Arquitetura em árvore:`**
```
projeto-pi-grupo10
├───Colaborativo
│         ├───BancoDeDados
│         ├───Documentacao
│         └───Prototipacao
└───Individuais
          ├───Arnold Santos
          ├───Davi Almeida
          ├───Gabriel Silva
          ├───Gabriella Vitoria
          ├───Julio Cézar
          ├───Leonardo Barbosa
```

## Sobre o projeto

O projeto tem como objetivo fornecer uma ferramenta de pesquisa para analisar o
crescimento da cana-de-açúcar em função dos insumos aplicados, permitindo estimar
volume e massa seca por colmo, acompanhar a evolução do crescimento ao longo do
tempo e comparação de custo-benefício entre diferentes insumos.
